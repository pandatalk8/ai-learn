# 自动化研究

一句话：用 agent + harness 把「出主意 → 写代码 → 跑实验 → 写论文/评估」组织成可迭代科研工作流；**论文流水线 ≠ 科学发现**。

## 在 RSI 中的位置

成熟 harness 支撑 auto-research 循环，是 [[递归自我改进]] 近端路径的重要形态：改进的是研究与训练流程，而不必直接改权重。

## 代表路线（Weng 综述）

| 系统 | 侧重点 |
|---|---|
| [[AI Scientist]] | 想法、代码、实验、手稿、评审流水线 |
| ScientistOne | 可验证性：claim 必须可追溯证据 |
| Autodata | 挑战者 / 强弱求解器 / 验证器合成数据 |
| [[ADAS]] | 元 agent 搜索 agentic 工作流代码 |
| [[AFlow]] | 工作流当图，用 MCTS 搜索 |

## 失败模式提醒

专家设计的 harness 可完成大量「像研究」的动作，但仍常见：伪造引用、实现漂移、过度乐观、领域判断弱、科学品味不足。评估研究品味与长期价值远难于单元测试。

相关瓶颈见 [[评估器设计]]、[[Reward hacking]]、负结果保留。
