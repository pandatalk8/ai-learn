## **🧵最近很多人问：OpenClaw 火了，普通人到底要不要跟？**

1/

OpenClaw 这段时间确实很火。

很多技术博主在讨论 Agent、系统控制、自动执行任务，看着挺酷。

但如果你不是程序员，可能会有点懵。

我自己在openclaw已经折腾了整整一个周了， 在我看来这个项目有巨大的启发意义，但是仍然是实验型项目，大量的普通用户根本没有能力参与进来。   



2/

很多人第一次接触 OpenClaw，会遇到这些问题：

- 需要命令行操作
- 要装 Node / pnpm
- 配环境变量
- 处理依赖冲突
- 报错全是英文

光是安装，就劝退一半人。

3/

你可能还需要：

- 熟悉终端
- 理解 Agent 架构
- 配浏览器权限
- 处理端口问题

这对技术圈来说很正常。

对普通用户来说，成本确实不低。

------



4/

很多人其实需求很简单：

我想让电脑帮我整理文件

我想自动处理重复工作

我想一键生成 PPT

我想远程控制我的电脑

就这么简单。

------



5/

最近看到一个方向更贴近日常使用的产品：

Yuanqi AI Bot

https://yuanqiai.net

它是桌面软件，安装后直接用。

不用进终端。

不用自己搭环境。

不用研究框架。
