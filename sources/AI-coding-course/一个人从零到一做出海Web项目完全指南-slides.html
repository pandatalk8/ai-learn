第一步

先搞清楚你要做什么

🎯

01 解决谁的问题？

一句话说清楚。比如「帮设计师批量去除图片背景」

去 Reddit 和 Product Hunt 找真实痛点
🏆

02 凭什么是你？

更便宜、更快、更聚焦某个细分场景——但不能是「我也做一个」

找 3-5 个竞品，列表格对比 功能 + 定价 + 差评
💰

03 怎么收钱？

订阅制、一次性买断、按量付费、免费增值——第一天就想清楚

收费模式决定 产品设计 + 技术架构
🧠

AI 能帮你写代码，但不能帮你想清楚做什么。产品方向错了，技术再好也白搭。

第二步

你真正需要知道的只有三件事

⌨️

会用终端

打开终端，能输入命令、切换目录、运行 npm run dev

🔀

理解 Git 最小概念

版本 · 分支 · 合并 · 回退
具体提交交给 AI

📂

知道文件怎么组织

页面在 app/，样式在 CSS 文件，配置在根目录。AI 告诉你改哪，你能找到就行

HTML、CSS、JavaScript 语法？不需要提前学。遇到不懂的直接问 AI。

第三步

技术栈——只用这一套

层选择为什么
⚛️ 前端框架Next.js（React）全栈框架，AI 代码生成质量最高
🎨 UI 组件shadcn/ui + Tailwind好看、开箱即用、复制粘贴
🗄️ 数据库Supabase免费、自带认证、可视化界面友好
🚀 部署Vercel推代码自动部署，免费额度够用
💳 支付Stripe全球通用，支持订阅和一次性付款
🌐 域名Cloudflare便宜、DNS 解析快

核心优势：AI 对这套技术栈最熟悉，生成代码的准确率远高于小众框架。

核心技巧

跟 AI 协作的四个原则

🗣️

01 给完整上下文

不要说「做一个登录页面」，要说「用 Next.js + Supabase，支持邮箱登录和 Google OAuth，用 shadcn/ui 组件，风格参考 linear.app」

🧩

02 一次只做一件事

今天做登录注册，明天做首页，后天做核心功能——每次一个明确的小任务

🐛

03 出错了喂报错信息

把终端里的红色报错完整复制给 AI，它通常能直接修好

💾

04 每完成一步让 AI 保存版本

你理解版本、分支、合并、回退和 git log，提交推送交给 AI

避坑

常见误区

❌
「我要先学完 React 再开始」
边做边学，遇到不懂的问 AI。你永远不会「准备好」
❌
「我的想法太简单了，不值得做」
Remove.bg 就是一个「去背景」功能，被 Canva 收购，估值上亿美元
❌
「我要把所有功能都做完再上线」
先做一个核心功能上线。没人用的产品，功能再多也没用
❌
「出海太难了，我英语不够好」
界面文案让 AI 写，客服邮件让 AI 回。用户需要你的产品，不需要跟你聊天
❌
「一个人做不了一个完整的产品」
一个人 + AI 的产出力相当于一个小团队。约束是判断力和执行力，不是人数
